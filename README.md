# 허영 국감 기록

2026년 국정감사(국토교통위원회)에서 허영 의원이 질의한 내용과 진행 상황, 관련 언론 보도를 정리한 원페이지 사이트입니다.
화면 구성은 대한민국 정부 디자인 시스템(KRDS)의 색·글꼴·간격 토큰을 따릅니다.

- `index.html`: 페이지 전체(HTML·CSS·JS 한 파일)
- `assets/heo-young.jpg`: 의원 사진
- `assets/panels/qNN.webp`: 질의서(HWP)에서 꺼낸 국감 패널. 질의 카드의 대표 이미지로 쓰입니다.

## GitHub Pages로 공개하기

1. 이 `site` 폴더의 내용만 새 저장소에 올립니다. 질의서 원본(HWP)은 올리지 않습니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<계정>.github.io/<저장소>/`에서 열립니다.

## 내용 수정

질의는 `index.html`의 `ITEMS` 배열에 있습니다.

- 기사 추가: `news` 배열에 `N("언론사","기사 제목","URL")`
- 패널 이미지: 질의에 `img:"assets/panels/q01.webp"`를 넣으면 카드에 표시됩니다. 없으면 핵심 수치가 대신 표시됩니다.
- 기관 답변·이행 결과: `reply:"답변 요지"`, `result:"조치 결과"`를 추가하면 질의 팝업에 표시됩니다.

질의마다 `#q01` 같은 주소가 있어 특정 질의로 바로 링크할 수 있습니다.
