# 2026 허영 의원 국정감사

국회의원 허영(더불어민주당, 국회 국토교통위원회)의 2026년 국정감사 질의를 모은 웹페이지입니다.

- **기간**: 2026. 10. 7. ~ 10. 23. (7일)
- **질의**: 51건
- **분야**: 공공기관·재정개혁 19건, 국민안전·품질관리 8건, 민생·주거사다리 복원 8건, 강원·춘천 균형발전 8건, 체감형 교통·이동권 8건

## 파일 구성

| 파일 | 설명 |
| :--- | :--- |
| `index.html` | 페이지 |
| `styles.css` | 스타일 |
| `app.js` | 일자별·분야별 필터, 검색, 질의 상세 팝업(`#item=1007-3` 같은 주소로 바로 열림) |
| `data.js` | 질의 데이터(페이지가 읽는 파일) |
| `data.json` | `data.js`와 같은 내용의 JSON |
| `slides/` | 질의서에 실린 국감 패널(WebP) |
| `profile.jpg` | 의원 사진 |

질의서 원본(`.hwp`)은 `.gitignore`로 제외되어 저장소에 올라가지 않습니다.

## 내용 수정

`data.json`을 고친 뒤 같은 내용을 `data.js`의 `window.AUDIT_DATA = ` 뒤에 넣습니다.

- 기사 추가: 질의의 `news`에 `{"press": "언론사", "title": "제목", "url": "주소", "date": "2026. 10. 30."}`
- 패널 추가: `slides/`에 이미지를 넣고 질의의 `slides`에 `{"src": "slides/파일명.webp", "caption": ""}`
